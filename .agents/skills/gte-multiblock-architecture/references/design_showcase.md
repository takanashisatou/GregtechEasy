# GTE 经典多方块建筑设计案例拆解 (Design Showcase)

通过解析 `gtecore` 中真实存在的经典多方块建筑设计，总结其空间组织、结构比例与细节处理的精髓。

## 案例 1: 精密元件工厂 (`Component_Factory_Multiblock`)

*风格：高精尖洁净室 (7x7x8 长方体跨度)*

### 建筑特征
- **底座与顶盖**：采用 `CASING_ALUMINIUM_FROSTPROOF` (防冻铝外壳) 封装，保证气密性。
- **立面结构**：中间大面积采用 `CLEANROOM_GLASS` (洁净室玻璃)，并在四角与中轴使用 `Aluminium` 框架进行加固。
- **内部空间**：内置双列 `CASING_STEEL_PIPE` (钢管道外壳)，形成两条流水线输送通道，保留中间通透空腔。

## 案例 2: 大型复合洗矿池 (`Big_Wash`)

*风格：重工石化/流体池 (7x7x5 台阶式阶梯水池)*

### 建筑特征
- **底部基座**：实心钢机械外壳封装，容纳底盘动力与排液管路。
- **反应水槽**：外圈为钢化玻璃围堰，内部直接填充真实流体方块 `minecraft:water`，让玩家在世界中可以直接看到翻滚的水体。
- **管道歧管**：在侧壁引出 `steel_pipe_casing` 作为进出水口，增强工业管道质感。

## 案例 3: 超弦振荡器阵列 (`SUPER_STRING_OSCILLATOR_ARRAY`)

*风格：深空科幻/高能物理对撞环 (31x31x22 巨型圆环与能量中轴)*

### 建筑特征
- **多层环形加速跑道**：外圈由 31x31 逐层缩进的 `SUPER_STRING_CASING` 构成流线型圆弧。
- **高能激发核心**：内部中心竖立垂直的 `SUPERCONDUCTING_COIL` (超导线圈) 反应柱。
- **辐射防护层**：在加速腔周围紧贴 `GTNNCasingBlocks.RADIATION_PROOF_MACHINE_CASING` 与 `MAR_CASING`，模拟真实高能粒子对撞机的防辐射层。
- **贵金属骨架支架**：四角与关键转折点镶嵌 `Europium` (铕) 和 `Iridium` (铱) 框架。

## 案例 4: 阴阳八卦高炉 (`YIN_YANG_EIGHT_TRIGMAS_BLAST_FURNACE`)

*风格：东方玄幻/宏大太极八卦阵列 (55x55 巨型平铺阵列 + 卫星神兽模块)*

### 建筑特征
- **太极双鱼图与八卦爻位**：以 55x55 的广阔空间，利用不同颜色和属性的五行外壳（`LI_HUO_CASING`, `KAN_SHUI_CASING`, `KUN_GEN_CASING`）拼出八卦阵图案。
- **主阵法与卫星模块分离**：核心高炉位于中心，而在东南西北四方特定相对坐标处，延伸出 `青龙`、`白虎`、`朱雀`、`玄武` 四大神兽模块阵列，通过代码动态检测激活加成。
