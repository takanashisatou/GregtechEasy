# GregTech Easy (GTE) Official Documentation

Welcome to the official documentation for the **GregTech Easy (GTE)** modpack!

GTE is a modern Minecraft 1.20.1 modpack built upon the core philosophy of **"Simple, fun, engaging, and respectful of player time."**
