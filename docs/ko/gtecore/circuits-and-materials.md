# 초끈과 음양 고급 회로 및 재료 시스템

GTECore는 ZPM에서 MAX까지의 전체 주기에 걸친 두 가지 고급 회로 분기인 **초끈 회로 시스템**과 **음양 태극 회로 시스템**을 확장하며, 광석 종합 처리 센터를 통해 자동화된 재료 대순환을 구현합니다.

---

## 🌌 초끈 회로 시스템 (Super String Circuitry)

초끈 회로는 고차원 진동 끈에서 초광속 연산 능력을 얻으며, 주로 **ZPM ➜ UEV** 전압 구간을 다룹니다:

```mermaid
graph LR
    A[초끈 기판 / 인쇄 회로 기판] --> B[초끈 프로세서 ZPM]
    B --> C[초끈 프로세서 클러스터 UV]
    C --> D[초끈 프로세서 슈퍼컴퓨터 UHV]
    D --> E[초끈 프로세서 메인프레임 UEV]
```

### 초끈 재료 및 끈 계열 물질
- **기원의 끈 (`item.gtecore.original_string`)**：고차원 우주 진동의 근원.
- **α끈 / β끈 / γ끈 (`alpha_string`, `beta_string`, `gamma_string`)**：서로 다른 에너지 준위와 편광 상태의 초끈 중합체.
- **초끈 혼합기 (`super_string_mixer`)**、**창세의 끈 (`string_of_creation`)** 및 **초끈 진동 배열 (`super_string_oscillator_array`)**：초끈 물질의 분열, 조율 및 고급 고형화에 사용됩니다.

## ☯️ 음양 태극 회로 시스템 (Yin-Yang Circuitry)

음양 회로 시스템은 **“음이 양을 낳고, 양이 음을 낳아, 끊임없이 이어지는”** 순환 상생 철학을 따르며, **UV ➜ UIV** 이상의 한계를 다룹니다:

```mermaid
graph LR
    A[음양 단결정 실리콘 / 웨이퍼] --> B[음양 프로세서 UV]
    B --> C[음양 프로세서 클러스터 UHV]
    C --> D[음양 프로세서 슈퍼컴퓨터 UEV]
    D --> E[음양 프로세서 메인프레임 UIV]
```

### 팔괘와 오행 전용 부적
- **오행 원소**：금 원소 (`jinyuansu`)、목 원소 (`muyuansu`)、수 원소 (`shuiyuansu`)、화 원소 (`huo`)、토 원소 (`tuyuansu`).
- **오행 부적**：금의 부적, 목의 부적, 수의 부적, 화의 부적, 토의 부적.
- **팔괘상과 칩**：건, 곤, 진, 손, 감, 리, 간, 태 여덟 가지 괘상 부석과 핵심 칩.
- **삼청의 입자 (`god_nugget`)**：천지 현황의 기운을 응집한 최고급 합성 매체.

## 💎 광석 종합 처리 센터 레시피 모드

**광석 종합 처리 센터 (`ore_process_center`)**는 7가지 표준화된 회로 모드를 사전 설정하며, 기계 내부에서 프로그래밍 회로 번호를 설정하여 전환할 수 있습니다:

| 회로 번호 | 공정 경로 | 적용 광물 유형 및 산출물 특징 | 산출 배율 |
| :---: | :--- | :--- | :---: |
| **회로 1** | 분쇄 ➜ 분쇄 ➜ 세광 | 기본 금속 광석(철, 구리, 주석 등) 빠른 양산 | 5배 주산출물 + 부산출물 |
| **회로 2** | 분쇄 ➜ 분쇄 ➜ 원심분리 | 고부가가치 희귀 경금속 광석 동반 | 5배 주산출물 + 원심분리 정제 부산출물 |
| **회로 3** | 분쇄 ➜ 세광 ➜ 열분리 ➜ 분쇄 | 고온 내화 광석, 귀금속 광석(백금계, 금은 등) | 5~6배 + 순수 금속 분말 |
| **회로 4** | 분쇄 ➜ 열분리 ➜ 분쇄 | 황화물 및 심한 복잡한 포획 광석 | 5배 + 특수 열분리 부산출물 |
| **회로 5** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 세광 | 희토류 광석 및 다단계 가용성 염 광석 | 6배 + 이중 세광 부산출물 |
| **회로 6** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 원심분리 | 방사성 중광석(우라늄, 토륨, 플루토늄계) 및 희토류 | 6배 + 정밀 원심분리 중금속 |
| **회로 8** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 전자기 선광 | 강자성 및 상자성 광물(자철석, 크롬, 티타늄 등) | 6~8배 + 전자기 순수 분말 |
