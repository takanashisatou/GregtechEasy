# 초끈과 음양 고급 회로 및 재료 시스템

GTECore는 ZPM부터 MAX까지 전 주기에 걸친 두 가지 고급 회로 분기인 **초끈 회로 체계**와 **음양 태극 회로 체계**를 확장하며, 광석 종합 처리 센터와 함께 자동화된 재료 대순환을 구현합니다.

---

## 🌌 초끈 회로 체계 (Super String Circuitry)

초끈 회로는 고차원 진동 끈에서 초광속 연산 능력을 얻으며, 주로 **ZPM ➜ UEV** 전압 구간을 포괄합니다:

```mermaid
graph LR
    A[超弦基板 / 印刷板] --> B[超弦处理器 ZPM]
    B --> C[超弦处理器集群 UV]
    C --> D[超弦处理器超级计算机 UHV]
    D --> E[超弦处理器主机 UEV]
```

### 초끈 재료와 끈 계열 물질
- **기원의 끈 (`item.gtecore.original_string`)**: 고차원 우주 진동의 근원.
- **α끈 / β끈 / γ끈 (`alpha_string`, `beta_string`, `gamma_string`)**: 서로 다른 에너지 준위와 편광 상태의 초끈 중합체.
- **초끈 혼합기 (`super_string_mixer`)**, **창세의 끈 (`string_of_creation`)** 및 **초끈 진동 배열 (`super_string_oscillator_array`)**: 초끈 물질의 분할, 조율 및 고급 고형화에 사용됩니다.

## ☯️ 음양 태극 회로 체계 (Yin-Yang Circuitry)

음양 회로 체계는 **“음이 양을 낳고, 양이 음을 낳아, 끊임없이 이어지는”** 순환 상생·상극 철학을 따르며, **UV ➜ UIV** 및 그 이상의 한계까지 포괄합니다:

```mermaid
graph LR
    A[阴阳单晶硅 / 晶圆] --> B[阴阳处理器 UV]
    B --> C[阴阳处理器集群 UHV]
    C --> D[阴阳处理器超级计算机 UEV]
    D --> E[阴阳处理器主机 UIV]
```

### 팔괘와 오행 전용 부적
- **오행 원소**: 금 원소 (`jinyuansu`), 목 원소 (`muyuansu`), 수 원소 (`shuiyuansu`), 화 원소 (`huo`), 토 원소 (`tuyuansu`).
- **오행 부적**: 금의 부적, 목의 부적, 수의 부적, 화의 부적, 토의 부적.
- **팔괘상과 칩**: 건, 곤, 진, 손, 감, 리, 간, 태 여덟 가지 괘상 부석과 핵심 칩.
- **삼청의 입자 (`god_nugget`)**: 천지현황의 기운을 응집한 최고급 합성 매개체.

## 💎 광석 종합 처리 센터 레시피 모드

**광석 종합 처리 센터 (`ore_process_center`)** 는 7가지 표준화된 회로 모드를 기본 제공하며, 기계 내부에서 프로그래밍 회로 번호를 설정하여 전환할 수 있습니다:

| 회로 번호 | 공정 경로 | 적용 광물 유형 및 산출물 특징 | 산출 배율 |
| :---: | :--- | :--- | :---: |
| **회로 1** | 분쇄 ➜ 분쇄 ➜ 세광 | 기초 금속 광석(철, 구리, 주석 등) 빠른 양산 | 5배 주 산출물 + 부산물 |
| **회로 2** | 분쇄 ➜ 분쇄 ➜ 원심 분리 | 부생하는 고부가가치 희유 경금속 광석 | 5배 주 산출물 + 원심 분리 정제 부산물 |
| **회로 3** | 분쇄 ➜ 세광 ➜ 열분리 ➜ 분쇄 | 고온 내화 광석, 귀금속 광석(백금족, 금·은 등) | 5~6배 + 순수 금속 분말 |
| **회로 4** | 분쇄 ➜ 열분리 ➜ 분쇄 | 황화물 및 심하게 복잡한 산재 광석 | 5배 + 특수 열분리 부산물 |
| **회로 5** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 세광 | 희토류 광석 및 다단계 가용성 염 광석 | 6배 + 이중 세광 부산물 |
| **회로 6** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 원심 분리 | 방사성 중광물(우라늄, 토륨, 플루토늄 계열) 및 희토류 | 6배 + 정밀 원심 분리 중금속 |
| **회로 8** | 분쇄 ➜ 세광 ➜ 분쇄 ➜ 전자기 선광 | 강자성 및 상자성 광물(자철석, 크롬, 티타늄 등) | 6~8배 + 전자기 순수 분말 |
